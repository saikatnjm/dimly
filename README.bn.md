# Dimly

[English](README.md) · **বাংলা** · [ওয়েবসাইট](https://saikatnjm.github.io/dimly/)

মনিটরের আলো থাকুক চোখের আরামে, ল্যাপটপের সাথে তাল মিলিয়ে।

লিনাক্সে সাধারণত শুধু ল্যাপটপের স্ক্রিনের আলো কমানো-বাড়ানো যায়। বাইরের মনিটরের আলো
কমাতে হলে মনিটরের বাটন টিপে মেনু ঘাঁটতে হয়। Dimly ক্যাবলের মাধ্যমেই (DDC/CI) মনিটরের
আসল ব্যাকলাইট নিয়ন্ত্রণ করে, আর সারাদিন মনিটরকে আপনার ল্যাপটপের সমান উজ্জ্বল রাখে।

## কী কী করে

- **প্রতিটি মনিটরের আলাদা ব্রাইটনেস ও কনট্রাস্ট স্লাইডার।** সাথে আছে Night, Evening,
  Day আর Max প্রিসেট, এক ক্লিকেই বদলে নিন। প্রতিটা প্রিসেট ব্রাইটনেস, কনট্রাস্ট আর উষ্ণতা
  একসাথে ঠিক করে দেয়, আর কোনটায় কতটা, সেটা উইন্ডো থেকে আপনিই বেছে নেন। চাইলে কোনো প্রিসেট
  কনট্রাস্ট বা উষ্ণতা যেমন আছে তেমনই রেখে দিতে পারে। কীবোর্ড, শর্টকাট বা সময়সূচিতে আলো
  বদলালে স্লাইডারও সাথে সাথে সরে যায়।
- **উষ্ণতা (ওয়ার্মথ):** একটা স্লাইডারেই সব স্ক্রিনে নীল আলো কমান, ডেস্কটপের নিজের নাইট লাইট
  দিয়ে। চলবে সূর্যাস্ত থেকে সূর্যোদয় পর্যন্ত, বা সারাক্ষণ। ডেস্কটপে নাইট লাইট না থাকলে (যেমন
  পুরনো Linux Mint-এ) Dimly নিজেই X11-এ স্ক্রিনের রং উষ্ণ করে দেয়।
- **ল্যাপটপের সাথে তাল মিলিয়ে:** ল্যাপটপের ব্রাইটনেস বাটন চাপলে বাইরের মনিটরও সাথে
  সাথে বদলায়। স্লাইডার টানলেও দুটো স্ক্রিনই বদলায়। একই লেভেলে ল্যাপটপ যদি মনিটরের চেয়ে
  মলিন দেখায়, **Laptop brighter by** দিয়ে ল্যাপটপকে কয়েক ধাপ উজ্জ্বল রাখুন।
- **প্রতিটা মনিটরের রঙের ভারসাম্য:** আলাদা ব্র্যান্ডের মনিটর পাশাপাশি এক রকম দেখাতে একটা
  স্লাইডার, এক দিকে ঠান্ডা (নীলচে), আরেক দিকে উষ্ণ (লালচে)। এটা মনিটরের নিজের লাল আর নীলের
  মান থেকেই একটু এদিক-ওদিক করে, আর পাশের বাটনে চাপ দিলে আগের অবস্থায় ফিরে যায়।
- **টপ বার থেকেই নিয়ন্ত্রণ:** উপরের বারে (Linux Mint-এ প্যানেলে) Dimly-র আইকনে ক্লিক করলেই
  ব্রাইটনেস, কনট্রাস্ট, উষ্ণতা আর প্রিসেট হাতের কাছে। আইকনটা ডানে, ঘড়ির পাশে বা বাঁয়ে রাখতে পারেন।
- **কীবোর্ড শর্টকাট:** <kbd>Super</kbd>+<kbd>F6</kbd> চাপলে আলো বাড়ে,
  <kbd>Super</kbd>+<kbd>F5</kbd> চাপলে কমে।
- **সময় বুঝে আলো বদলায়:** দিনের কোন সময়ে কোন প্রিসেট থাকবে ঠিক করে দিন, Dimly নিজেই
  বদলে নেবে। সন্ধ্যা যত গড়াবে, স্ক্রিন তত মৃদু আর উষ্ণ হবে। মাঝখানে আপনি নিজে বদলালে
  সেটাই থাকবে পরের নির্ধারিত সময় পর্যন্ত।
- **একাধিক মনিটর একসাথে:** একটা মনিটরের স্লাইডার সরালে বাকিগুলোও সাথে সাথে সরে, প্রত্যেকটা
  নিজের মাপে। আলাদা আলাদা ঠিক করতে চাইলে **Keep monitors in sync** বন্ধ করুন; শর্টকাট, মেনু,
  প্রিসেট আর সময়সূচি তখনও সবগুলো একসাথেই বদলায়।
- **নতুন মনিটর লাগালেই চলে:** মনিটরগুলো সিঙ্কে থাকলে নতুনটাও নিজে থেকে বাকি স্ক্রিনগুলোর
  সমান উজ্জ্বলতায় চলে আসে।
- **ফ্যাক্টরি রিসেট:** কোনো মনিটর যদি ব্রাইটনেস বদলালেও আর ডিম না হয়, এক ক্লিকে রিসেট
  করে ঠিক করা যায়। আপনার ব্রাইটনেস, কনট্রাস্ট আর রঙের সেটিংস আগের মতোই থাকে।

GNOME 42 থেকে 50 (Ubuntu 22.04 থেকে 26.04) আর Linux Mint-এর Cinnamon-এর জন্য বানানো;
Cinnamon-এ মেনুটা থাকে প্যানেলে। Cinnamon-এ ল্যাপটপ সিঙ্ক আর আপনা-আপনি কীবোর্ড শর্টকাট এখনো
নেই; Mint-এর Keyboard সেটিংস থেকে `dimly --up` আর `dimly --down` কোনো কী-তে বসিয়ে নিতে পারেন।

## ইনস্টল

### Ubuntu / Debian প্যাকেজ দিয়ে

[dimly_latest_all.deb](https://github.com/saikatnjm/dimly/releases/latest/download/dimly_latest_all.deb) ফাইলটা নামিয়ে নিন, এটা সবসময় সর্বশেষ ভার্সন
(প্রতিটা ভার্সন [রিলিজ পেজেও](https://github.com/saikatnjm/dimly/releases) আছে)। তারপর
যে ফোল্ডারে ফাইলটা রেখেছেন, সেখানে চালান:

```bash
sudo apt install ./dimly_latest_all.deb
```

এরপর একবার লগ আউট করে আবার লগ ইন করুন, তাহলে আপনার অ্যাকাউন্ট মনিটরের সাথে যোগাযোগ
করতে পারবে আর GNOME টপ বারের মেনুটা চিনে নেবে। তারপর অ্যাপ মেনু থেকে **Dimly** খুলুন।
প্রথমবার খোলার সময় এটা নিজেই কীবোর্ড শর্টকাট বসিয়ে নেয়, দরকারি সার্ভিসগুলো চালু করে
দেয় আর টপ বারে আইকনটা দেখায়।

### নতুন ভার্সনে আপডেট

নতুন `.deb` ফাইলটা নামিয়ে একইভাবে ইনস্টল করুন। আগেরটা আনইনস্টল করার দরকার নেই: apt
পুরনো ভার্সনের জায়গায় নতুনটা বসিয়ে দেয়, আর আপনার সেটিংস, সময়সূচি ও প্রিসেট যেমন ছিল তেমনই
থাকে। তারপর লগ আউট করে আবার লগ ইন করুন, যাতে GNOME আর ব্যাকগ্রাউন্ড সার্ভিস নতুন ভার্সনটা
চালু করে।

### আনইনস্টল

```bash
dimly --remove-setup && sudo apt remove dimly
```

প্রথম অংশটা আপনার অ্যাকাউন্টে Dimly যা যা সেট করেছিল সেগুলো সরিয়ে দেয়: কীবোর্ড শর্টকাট,
টপ বারের মেনু আর ব্যাকগ্রাউন্ড সার্ভিস। এটা প্যাকেজ সরানোর আগেই চালান, কারণ পরে `dimly`
কমান্ডটা আর থাকবে না। আবার ইনস্টল করলে কাজে লাগবে বলে আপনার সেটিংস `~/.config/dimly`-তে
থেকে যায়; সেগুলোও মুছতে চাইলে:

```bash
rm -rf ~/.config/dimly ~/.cache/dimly ~/.local/state/dimly
```

প্যাকেজ আগেই সরিয়ে ফেলে থাকলে GNOME Settings → Keyboard → Custom Shortcuts থেকে "Dimly"
নামের এন্ট্রি দুটো মুছে দিন। এছাড়া আর কিছু চালু থাকে না।

### সোর্স কোড থেকে

এর জন্য লাগবে `ddcutil`, Python 3.10 বা তার পরের ভার্সন, GTK 4 আর libadwaita:

```bash
sudo apt install ddcutil python3-gi gir1.2-gtk-4.0 gir1.2-adw-1
```

এরপর নিচের [সেটআপ](#সেটআপ) ধাপগুলো সেরে `./install.sh` চালান। এটা শুধু আপনার
অ্যাকাউন্টে (`~/.local`-এ) ইনস্টল হয়। কোডে কিছু বদলালে আবার চালালেই হবে। সরিয়ে ফেলতে
চাইলে `./uninstall.sh` চালান।

## সেটআপ

প্যাকেজ দিয়ে ইনস্টল করলে প্রথম দুটো ধাপ নিজে থেকেই হয়ে যায়।

**ধাপ ১:** কম্পিউটার চালু হলেই যেন `i2c-dev` মডিউল লোড হয়:

```bash
echo i2c-dev | sudo tee /etc/modules-load.d/dimly.conf && sudo modprobe i2c-dev
```

**ধাপ ২:** আপনার অ্যাকাউন্টকে মনিটর নিয়ন্ত্রণের অনুমতি দিন। Dimly-র udev রুলটা কপি করে
রিলোড করুন:

```bash
sudo cp data/60-dimly-i2c.rules /etc/udev/rules.d/ && sudo udevadm control --reload-rules && sudo udevadm trigger --subsystem-match=i2c-dev
```

এরপর একবার লগ আউট করে আবার লগ ইন করুন।

**ধাপ ৩:** মনিটরের নিজস্ব মেনুতে DDC/CI নামে কোনো অপশন থাকলে সেটা চালু রাখুন।
বেশিরভাগ মনিটরে এটা আগে থেকেই চালু থাকে।

সব ঠিক আছে কিনা দেখতে এই কমান্ডটা চালান। মনিটরের এখনকার ব্রাইটনেস দেখালে বুঝবেন কাজ
করছে:

```bash
ddcutil getvcp 10
```

## কীভাবে ব্যবহার করবেন

| কী করতে চান | কীভাবে |
|---|---|
| সব স্ক্রিনের ব্রাইটনেস একসাথে বদলাতে | ল্যাপটপের ব্রাইটনেস বাটন, টপ বারে Dimly-র আইকন, Brightness স্লাইডার, অথবা <kbd>Super</kbd>+<kbd>F6</kbd> / <kbd>F5</kbd> |
| টপ বারের আইকন লুকাতে | উইন্ডোতে **Show Dimly in the top bar** বন্ধ করে দিন |
| টপ বারের আইকন সরাতে | **Position**-এ **Right**, **Next to the clock** বা **Left** বেছে নিন |
| কোনো প্রিসেট কী করবে, তা বদলাতে | **Presets** অংশে প্রিসেটটা খুলে ব্রাইটনেস, কনট্রাস্ট আর উষ্ণতা ঠিক করুন। 0-এর নিচে মানে **Keep**: প্রিসেট ওই সেটিংয়ে হাত দেবে না |
| সময়সূচি বদলাতে | **Schedule** অংশে সময় আর প্রিসেট ঠিক করে দিন |
| শর্টকাটের কী বদলাতে | GNOME Settings → Keyboard → Custom Shortcuts |
| ল্যাপটপের স্ক্রিন আলাদা রাখতে | **Sync** অংশে **Keep the laptop screen in sync** বন্ধ করে দিন |
| প্রতিটা মনিটর আলাদা করে ঠিক করতে | **Keep monitors in sync** বন্ধ করুন (দুই বা তার বেশি মনিটর থাকলে দেখা যায়) |
| ল্যাপটপকে মনিটরের মতো দেখাতে | **Laptop brighter by** ঠিক করুন, যেমন 10; 0-এর নিচে দিলে ল্যাপটপ মৃদু থাকে |
| এক মনিটরের রং অন্য স্ক্রিনের সাথে মেলাতে | ওই মনিটরের **Colour** স্লাইডার সরান; পাশের বাটনে আগের মতো হয়ে যায় |

টার্মিনাল থেকেও চালানো যায়:

```bash
dimly --up
```

এছাড়া আছে `--down`, `--set 40` আর `--preset Night`। সব অপশন দেখতে `dimly --help`
চালান।

### সেটিংস ফাইল

সেটিংস রাখা থাকে `~/.config/dimly/config.json` ফাইলে। প্রিসেটগুলোর লেভেলসহ প্রায় সবকিছুই
উইন্ডো থেকে বদলানো যায়। শুধু শর্টকাটে প্রতিবার কতটা বাড়বে-কমবে, সেটা বদলাতে হলে ফাইলটা এডিট
করুন:

```json
{
  "step": 10
}
```

## সমস্যা হলে

- **"No adjustable monitor found" দেখালে:** মনিটরের মেনুতে DDC/CI চালু আছে কিনা দেখে
  নিন। অনেক USB-C ডক আর DisplayLink অ্যাডাপ্টার DDC/CI সাপোর্ট করে না, তাই মনিটরটা
  সরাসরি HDMI বা DisplayPort দিয়ে লাগিয়ে দেখুন।
- **সংখ্যা বদলায়, কিন্তু স্ক্রিনের আলো বদলায় না:** কিছু মনিটর মাঝে মাঝে এভাবে আটকে যায়।
  উইন্ডোতে ওই মনিটরের অংশে **Factory reset** চাপুন।
- **ল্যাপটপের এক-আধ সেকেন্ড পরে মনিটর বদলায়:** এটা স্বাভাবিক। প্রতিটা পরিবর্তন নিতে
  মনিটরের প্রায় আধা সেকেন্ড লাগে।

## ভেতরে কীভাবে কাজ করে

মনিটরে প্রতিটা নির্দেশ পাঠাতে Dimly `ddcutil` ব্যবহার করে। একসাথে একাধিক নির্দেশ গেলে
সেগুলো ক্যাবলে জট পাকিয়ে যায়, আর ধীরগতির মনিটর কিছু নির্দেশ হারিয়ে ফেলে। তাই Dimly
একটা একটা করে পাঠায়। ল্যাপটপের স্ক্রিন নিয়ন্ত্রণ হয় GNOME-এর মাধ্যমে, আর ব্যাকগ্রাউন্ডে
একটা ছোট সার্ভিস ল্যাপটপের ব্রাইটনেসের দিকে নজর রাখে এবং নতুন মনিটর এল কিনা দেখে।
